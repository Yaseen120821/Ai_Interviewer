## 1. Overview & Objectives

In MockMate AI, the candidate profile (`/profile`) serves as the central identity anchor. Interview questions generated by Google Gemini are directly personalized using the candidate's target job role, experience level, skill proficiencies, and resume highlights.

Key capabilities delivered:
1. **Personal Information:** Name, email, phone, location, bio/elevator pitch, and current job title.
2. **Career Targets:** Target job role, target industry (e.g. Fintech, SaaS, E-Commerce), years of experience, and expected salary range.
3. **Interactive Skill Proficiencies:** Candidates can dynamically add and remove skill chips, each categorized by proficiency tier (`Beginner`, `Intermediate`, `Advanced`, `Expert`).
4. **Validated Social & Developer Links:** Direct integration fields for LinkedIn, GitHub, LeetCode, and personal portfolio with URL regex validation.
5. **Spark Plan Compliant PDF Resume Management:** Resumes are uploaded to Express backend disk storage (`/uploads/resumes`) to strictly comply with the Firebase Spark free plan (zero Firebase Storage costs).
6. **Profile Completeness Score (0-100%):** Real-time progress meter showing which profile sections need completion.

## 2. Profile Completeness Algorithm

The completeness score dynamically evaluates 7 distinct dimensions:

```javascript
// client/src/pages/profile/ProfilePage.jsx
const calculateCompleteness = (profileData) => {
  let score = 0;
  if (profileData.name && profileData.email) score += 20; // Basic Identity
  if (profileData.bio && profileData.bio.length >= 20) score += 15; // Candidate Bio
  if (profileData.targetRole) score += 15; // Career Target
  if (Array.isArray(profileData.skills) && profileData.skills.length >= 3) score += 20; // 3+ Skills
  if (profileData.github || profileData.linkedin) score += 15; // Professional Links
  if (profileData.resumeFileName || profileData.resumeUrl) score += 15; // Resume Uploaded
  return Math.min(100, score);
};
```

## 3. Skill Proficiency Chip Architecture

Candidates add skills through a modal or inline bar. Each skill is stored as an object:
```json
{
  "name": "React",
  "level": "Expert"
}
```

The UI renders each skill chip with a dedicated color badge corresponding to its tier:
- `Beginner`: Neutral Grey (`#6B7280`)
- `Intermediate`: Blue (`#2563EB`)
- `Advanced`: Indigo (`#4F46E5`)
- `Expert`: Emerald (`#059669`)

## 4. Local Resume Management Architecture (Spark-Plan Free Tier)

Because Firebase Storage requires a Blaze plan billing account for production uploads, MockMate AI routes PDF resumes through the local Express server:

```
[Candidate selects PDF]
          │
          ▼
  `POST /api/v1/resume/upload` (multipart/form-data)
          │
          ▼
  Express Server: Multer saves file to `server/uploads/resumes/<timestamp>-<name>.pdf`
          │
          ▼
  Returns `{ success: true, fileUrl: "/uploads/resumes/...", fileName: "..." }`
          │
          ▼
  Client saves metadata to Firestore doc `users/{uid}`:
  - `resumeUrl`: Local download URL
  - `resumeFileName`: Original filename
  - `resumeUploadedAt`: Timestamp
```

## 5. Security & Verification

- **User Isolation:** All updates are strictly constrained to `users/{uid}` where `uid` matches the active Firebase authenticated user ID.
- **XSS & URL Validation:** LinkedIn, GitHub, and LeetCode input fields are scrubbed to ensure valid URLs before submission.
- **Persistence Verification:** Data saved on the Profile page immediately synchronizes across the Dashboard and Setup Wizard without page refreshes.
